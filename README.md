## 📲 PWA deinstallieren

Falls du die alte Version als App installiert hast, bitte deinstallieren –  
die App erhält **keine Updates mehr**.

**Chrome / Edge (Desktop):**
1. App öffnen → Menü (⋮) oben rechts → „Windows Admin Cheatsheet deinstallieren"

**Android (Chrome):**
1. Startbildschirm → App-Symbol gedrückt halten → „Deinstallieren" / „Vom Startbildschirm entfernen"

**iPhone / iPad (Safari):**
1. Startbildschirm → App-Symbol gedrückt halten → „App löschen"
